던전앤코파일럿 워크샵

오늘 진행할 워크샵은 Copilot과 함께 나만의 식당을 기획해보는 참여형 실습입니다. 여러분은 이제부터 창업을 앞둔 예비 오너가 되어, 시장 트렌드를 읽고 상권 데이터를 분석하고 브랜드 콘셉트와 발표 자료까지 완성해봅니다.

01 · Copilot에게 미션 주기

Copilot이 더 좋은 답을 하도록 목표, 배경, 참고자료, 결과 형식을 분명하게 요청하는 법을 익힙니다.

02 · 나만의 식당 만들기

시장 조사부터 데이터 분석, 메뉴, 브랜드 기획까지 이어가며 내 식당의 방향을 구체화합니다.

03 · 런칭 발표

마지막에는 만든 식당 콘셉트를 짧게 공유합니다. 마지막에는 내가 만든 식당을 동료들에게 발표해보세요!

    파일이 PC로 다운로드된 경우에는 OneDrive 웹에 업로드한 뒤 Excel 웹에서 열어주세요.

    ① Create or upload → Files upload

    ② 파일이 OneDrive에 올라온 것 확인

    ① OneDrive → Create or upload → Files upload

    ② 인천공공데이터 파일 확인

    ③ Excel 웹에서 복사본 편집 클릭

  1. 각 아젠다의 내용을 Word Copilot으로 새로 작성하거나, 일부 영역을 선택하여 수정할 수 있습니다.

🚩 프리젠테이션 작성

참조 파일(워드)을 사용하여 프리젠테이션을 만들 수 있습니다.

샘플 프롬프트

/(기획서 파일) 을 바탕으로 우리 식당을 소개하는 발표 자료를 만들어줘. 식당 컨셉, 타겟 고객, 메뉴 구성, 브랜드 아이덴티티 순서로 구성해줘.

/(기획서 파일) 을 바탕으로 투자자에게 설명하는 발표 자료를 만들어줘. 시장 데이터, 차별화 전략, 예상 수익 모델을 중심으로 설득력 있게 구성해줘.

/(기획서 파일) 을 바탕으로 동네 주민에게 새 맛집을 소개하는 발표 자료를 만들어줘. 따뜻하고 친근한 톤으로, 메뉴 하이라이트와 오픈 이벤트 정보가 잘 보이게 해줘.

/(기획서 파일) 을 바탕으로 SNS 마케팅 캠페인 기획안 슬라이드를 만들어줘. 타겟 채널, 콘텐츠 아이디어, 오픈 이벤트 플랜이 한눈에 들어오게 구성해줘.

💡 디자인 선택에서 원하는 템플릿을 지정하여 프리젠테이션을 생성할 수 있습니다.

  1. Copilot이 생성한 구조를 확인하고, 추가 또는 삭제를 선택하여 아젠다를 확정합니다.
  2. 특정 슬라이드에서 이미지를 생성하려면 Copilot Chat 패널을 열고, 프롬프트 입력창에 원하는 이미지를 요청합니다. 필요에 따라 이미지 모델도 직접 선택할 수 있습니다.
  3. Copilot이 생성한 슬라이드 구조를 확인합니다. 슬라이드를 직접 편집하거나, Copilot Chat에 "3번 슬라이드 내용을 더 구체적으로 써줘" 처럼 추가 수정을 요청할 수 있습니다.
  4. Stage 5에서 생성한 로고·메뉴판·홍보 포스터 이미지를 활용해 발표 자료의 핵심 메시지를 다듬습니다.
  5. 필요한 경우 PowerPoint 웹 안에서 슬라이드 디자인이나 이미지 생성을 요청해 시각 요소를 보강합니다.
🚩 발표 자료 마무리 프롬프트

PowerPoint 웹에서 발표 자료를 다듬을 때 사용할 수 있는 추천 프롬프트입니다.

샘플 프롬프트

전체 슬라이드 흐름을 검토하고, 설득력이 약한 부분을 찾아 개선해줘. 슬라이드 순서와 핵심 메시지도 다듬어줘.

표지 슬라이드를 더 임팩트 있게 바꿔줘. 우리 식당 컨셉과 타겟 고객이 한눈에 보이도록 레이아웃과 문구를 제안해줘.

앞에서 만든 로고, 메뉴판, 홍보 포스터 이미지를 이 발표 자료에 넣어줘. 어느 슬라이드에 배치하면 좋을지 제안하고, 캠페인 콘셉트를 한 슬라이드로 요약해줘.
