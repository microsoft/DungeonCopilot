# 던전앤코파일럿 8

Microsoft 365 Copilot 퀴즈 던전 RPG — 코파일럿 익스피리언스 부스용 웹게임

빌드 도구 없이 순수 HTML/CSS/JS로 동작하는 정적 사이트입니다.

## 바로 해보기

**▶ https://microsoft.github.io/DungeonCopilot/dnc8_k/**

설치가 필요 없고, 링크만 열면 바로 시작합니다.

## 로컬에서 실행

**권장:** 폴더의 `서버로-열기.bat`을 더블클릭하세요. 로컬 서버가 뜨고 브라우저가 자동으로 열립니다.

```bash
# 직접 실행하려면
cd dnc8_k
python -m http.server 8848
# http://localhost:8848
```

> **`index.html`을 파일로 직접 열지 마세요(`file://`).** 브라우저 보안 정책 때문에 **게임패드가 인식되지 않고** 몬스터 초상화가 표시되지 않을 수 있습니다. `file://`로 열면 타이틀 화면에 경고가 표시됩니다.

## 네트워크가 차단된 환경

폴더를 통째로 복사해 로컬 서버로 열면 그대로 동작합니다. 외부에서 받아오는 것은 **Google Fonts뿐**이며, 차단되어도 시스템 폰트(맑은 고딕 / monospace)로 대체되어 레이아웃이 깨지지 않습니다. 이미지·사운드·퀴즈 데이터는 모두 폴더 안에 있습니다.

픽셀 폰트까지 그대로 살리려면 폰트 파일을 `assets/fonts/`에 내려받고 `index.html`의 Google Fonts `<link>`를 로컬 `@font-face`로 교체하세요.

### 게임패드가 인식되지 않을 때

`gamepad-test.html`을 열어 진단하세요. 가장 흔한 원인은 두 가지입니다.

1. **패드 버튼을 아직 누르지 않음** — 브라우저는 지문 방지 정책상, 페이지에서 버튼이 한 번 눌리기 전까지 패드를 노출하지 않습니다. 연결만 해서는 감지되지 않습니다.
2. **`file://`로 열었음** — 위 안내대로 로컬 서버로 여세요.

그 외: 브라우저 창에 포커스가 있어야 하며, Xbox 패드는 유선 또는 전용 무선 어댑터를 권장합니다. `Win+R` → `joy.cpl`로 OS 인식 여부를 먼저 확인하세요.

### 8BitDo Micro 사용법

Micro는 본체 **하단 가장자리의 물리 슬라이더(S / D / K)**로 모드를 바꿉니다. 버튼 조합이 아닙니다.

**D 모드를 쓰세요.** 공식 스펙은 "Windows는 키보드 모드만"이라고 하지만, 실제로는 D 모드가 게임패드로 정상 인식됩니다.

1. 슬라이더를 **D**로
2. **Home** 버튼으로 전원 켜기 (끄기: Home 3초)
3. 최초 연결이면 **pair 버튼 1초** → LED 빠르게 점멸
4. Windows 블루투스 설정에서 **8BitDo Micro gamepad** 연결
5. 게임에서 패드 버튼을 한 번 누르면 인식됩니다

> 모드를 바꾼 뒤에는 **전원을 껐다 켜야** 적용되며, 모드마다 페어링 정보가 따로 저장됩니다.

Micro는 닌텐도 배열이라 Gamepad API 인덱스와 각인이 어긋납니다(2번이 Y, 3번이 X). 게임은 이를 보정해 **A · B · Y · X** 순서로 라벨을 표시합니다.

## 게임 방식

타이틀 화면에서 두 가지 중 고릅니다.

### 던전 모드
탐험하며 여러 문제에 도전하는 RPG. 이름을 입력하고 리더보드에 기록이 남습니다.

| 항목 | 값 |
|---|---|
| 시작 체력 | 10 |
| 포털 개방 조건 | 스테이지당 10점 |
| 하급 몬스터(슬라임) | +3점 / 오답 -2HP |
| 중급 몬스터(고블린 전사) | +6점 / 오답 -3HP |
| 상급 몬스터(데몬 로드) | +10점 / 오답 -5HP |

- 몬스터와 충돌하면 해당 등급의 퀴즈가 출제됩니다.
- 정답이면 몬스터를 처치하고 점수를 얻습니다.
- 오답이면 체력이 깎이고 몬스터는 4초간 물러납니다(재도전 가능).
- 체력이 0이 되면 게임이 종료되고 리더보드에 기록됩니다.
- 스테이지가 깊어질수록 몬스터가 빨라지고 상급 출현율이 올라갑니다.
- 더 깊은 스테이지에 도달할수록 더 좋은 보상을 받습니다(보상 내용은 현장 안내).

### 탐험 모드
한 사람이 문제 하나만 풀고 끝나는 단발성 모드. 부스 회전율이 필요할 때 씁니다.

1. **도전 시작** → 슬롯이 돌며 난이도를 뽑습니다 (하 50% · 중 35% · 상 15%)
2. 뽑힌 난이도의 문제가 하나 나옵니다
3. 맞히면 **축하합니다**, 틀리면 **실패 — 다시 도전하세요**
4. 정답과 해설을 보여준 뒤 **다음 도전자**로 바로 넘어갑니다

이름 입력이 없고 기록도 남지 않습니다. 리더보드는 던전 모드 전용입니다.

## 난이도

| 난이도 | 던전 모드 | 탐험 모드 |
|---|---|---|
| **일반** | 하·중·상 몬스터가 섞여 등장 | 슬롯으로 난이도 결정 |
| **헬** | 상급 몬스터만 등장 | 슬롯 없이 항상 상급 문제 |

헬 난이도는 오답 한 번에 5HP가 깎여 던전 모드에서는 두 번만 틀려도 종료됩니다.

## 조작

| 동작 | 키보드 | 마우스 / 터치 | 게임패드 |
|---|---|---|---|
| 이동 | 방향키 / WASD | **바닥 클릭 → 자동 이동** | 왼쪽 스틱 / D-패드 |
| 답변 선택 | 1 · 2 · 3 · 4 | 클릭 | A · B · Y · X |
| 계속하기 / 시작 | Enter | 클릭 | A 또는 Start |
| **일시정지** | **ESC** | ⏸ 버튼 | **Start** |
| 타이틀로 | — | 클릭 | B (게임오버 화면) |
| 음소거 | M | 소리 버튼 | Back/Select |

> **바닥을 클릭하면 그 지점까지 알아서 걸어갑니다.** 최단 경로를 찾아 벽을 피해 이동하며, 목적지에 금색 표식이 표시됩니다. 이동 중 **방향키를 누르면 즉시 수동 조작으로 전환**되고, 도중에 몬스터와 부딪히면 전투가 시작됩니다. 벽을 클릭하면 무시됩니다. 터치스크린에서도 같은 방식으로 동작합니다.

> **보기 라벨은 자동으로 바뀝니다.** 패드가 없으면 `1 2 3 4`, 패드가 연결되면 `A B Y X`로 표시되어 실제 눌러야 할 버튼과 일치합니다. 전투 중에 패드를 연결해도 즉시 반영됩니다.

게임패드는 연결 후 **아무 버튼이나 한 번 누르면** 인식됩니다(브라우저 정책).

## 중간에 나가기

플레이 중 **ESC**(또는 게임패드 **Start**)를 누르면 일시정지 메뉴가 열립니다. HUD 우측의 ⏸ 버튼으로도 열 수 있습니다.

| 선택지 | 단축키 | 동작 |
|---|---|---|
| 계속하기 | ESC · A | 게임으로 복귀 |
| 기록 남기고 종료 | Q · B | 현재 스테이지·점수를 리더보드에 저장하고 결과 화면으로 |
| 기록 없이 나가기 | — | 확인 후 기록 없이 타이틀로 (다음 참가자 대기용) |

일시정지 중에는 몬스터도 함께 멈추고 화면이 어두워집니다.

## 퀴즈 확장 (모드 추가)

현재는 **Microsoft 365 Copilot** 모드만 있습니다(사용자 관점 110문항 — 하급 50 / 중급 30 / 상급 30).
하급은 부스를 처음 방문한 사람도 부담 없이 맞힐 수 있는 수준으로 맞췄습니다.
`js/quiz.js`의 `QUIZ_MODES`에 항목을 추가하면 타이틀 화면에 모드 선택 버튼이 자동으로 생깁니다.

```js
QUIZ_MODES.github = {
  label: 'GitHub Copilot',
  desc: '개발자를 위한 코파일럿',
  banks: {
    low:  [ { q: '질문', a: ['보기1','보기2','보기3','보기4'], c: 0, exp: '해설' } ],
    mid:  [ /* ... */ ],
    high: [ /* ... */ ]
  }
};
```

- `c`는 정답 보기의 인덱스(0부터)이며, 실제 출제 시 보기 순서는 자동으로 섞입니다.
- 등급별 문항이 모두 출제되면 해당 등급만 자동으로 재사용됩니다.

## 밸런스 조정

`js/game.js` 상단의 `CONFIG`에서 수정합니다.

```js
MAX_HP: 10,            // 시작 체력
STAGE_GOAL: 10,        // 포털 개방 점수
RESPAWN_MS: 6000,      // 몬스터 리스폰 주기
GRID: 19,              // 던전 한 변의 타일 수
TIER: { ... },         // 등급별 점수·피해량·이동속도·제한시간
```

탐험 모드의 슬롯 확률과 연출 속도는 `js/solo.js` 상단에서 조정합니다.

```js
const SOLO = {
  WEIGHTS: { low: 50, mid: 35, high: 15 },  // 난이도 출현 가중치
  SPIN_MS: 1700,   // 릴이 도는 시간
  TICK_MS: 90      // 릴 한 칸 넘어가는 간격
};
```

> 보상(굿즈)은 게임 화면에 표시하지 않습니다. 도달 스테이지와 점수만 보여주고, 실제 보상은 현장 스태프가 안내합니다.

## 리더보드

브라우저 `localStorage`에 저장됩니다(도전자별 최고 기록). 타이틀 화면의 **기록 초기화** 버튼으로 비울 수 있습니다.
저장 키는 `dnc8_`로 시작해 같은 도메인의 다른 버전과 섞이지 않습니다.

> 부스에서 여러 대를 운영하면 기기별로 기록이 따로 쌓입니다. 통합 집계가 필요하면 `js/leaderboard.js`의 저장 로직을 서버 API로 교체하면 됩니다.

## 파일 구성

```
dnc8_k/
├── index.html
├── 서버로-열기.bat      # 로컬 서버 실행 (권장 실행 방법)
├── gamepad-test.html    # 게임패드 진단 페이지
├── css/style.css
├── assets/
│   ├── title.png        # 타이틀 아트 (Azure OpenAI gpt-image-2 생성)
│   └── monsters.png     # 몬스터 3종 초상화 시트
└── js/
    ├── quiz.js          # 퀴즈 뱅크 (모드별)
    ├── sprites.js       # 코드로 그린 도트 스프라이트
    ├── audio.js         # 칩튠 BGM·효과음 (Web Audio 합성)
    ├── leaderboard.js   # 리더보드 저장/조회
    ├── game.js          # 게임 상태·던전 생성·루프
    ├── render.js        # 캔버스 렌더러
    ├── battle.js        # 던전 모드 퀴즈 전투
    ├── solo.js          # 탐험 모드 (슬롯·단발 문제)
    ├── ui.js            # 화면·HUD·모달 제어
    ├── gamepad.js       # 게임패드 입력
    └── main.js          # 부트스트랩·키보드 입력
```

사운드는 외부 파일 없이 Web Audio API로 실시간 합성합니다(던전/전투/보스 BGM + 효과음).
캐릭터·몬스터·타일 스프라이트는 코드로 그려 픽셀 정합성을 유지하고, 타이틀 아트와 배틀 초상화만 이미지 에셋을 사용합니다.
