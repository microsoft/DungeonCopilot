# 코파일럿 월드 (Copilot World)

Microsoft 365 Copilot 기능 체험 플랫포머 — 코파일럿 익스피리언스 부스용 웹게임

빌드 도구 없이 순수 HTML/CSS/JS로 동작하는 정적 사이트입니다.
`Dungeon & Copilot` 시리즈의 새 장르로, 퀴즈 던전(dnc 계열)과 달리
**기능을 하나씩 손으로 써 보게 만드는 것**이 목적입니다.

## 바로 해보기

**▶ https://microsoft.github.io/DungeonCopilot/cpw_k/**

설치가 필요 없고, 링크만 열면 바로 시작합니다.

## 무엇을 배우게 되나

스테이지마다 Copilot 기능을 **파워업**으로 얻고,
**그 기능이 없으면 지나갈 수 없는 관문**을 배치했습니다.
설명을 듣는 대신 몸으로 익히게 하는 구조입니다.

| 스테이지 | 무대 | 획득 능력 | 관문 | 전하는 메시지 |
|---|---|---|---|---|
| 1-1 | 채팅 평원 | 💬 프롬프트 `Copilot Chat` | 혼자 못 넘는 5칸 벽 | 막히면 물어본다 |
| 1-2 | 워드 성 | 📄 초안 `Copilot in Word` | 발 디딜 곳 없는 낭떠러지 | 백지에서 출발하지 않는다 |
| 1-3 | 엑셀 광산 | 📊 분석 `Analyst` | 쌓인 데이터 벽 | 데이터는 뚫고 지나간다 |
| 1-4 | 리서치 탑 | 🔎 근거 `Researcher` | 안개에 가려진 발판 | 근거가 있어야 길이 보인다 |
| 1-5 | 코워크 성 | — | 보스 (앞의 3개 능력 전부 필요) | 혼자 다 하지 않아도 된다 |

각 스테이지를 깨면 그 기능에 대한 **확인 문제**가 한 문항 나옵니다. 정답 +100점.

## 조작

| 동작 | 키보드 | 게임패드 | 터치 |
|---|---|---|---|
| 이동 | ← → / A D | 왼쪽 스틱 · D-패드 | ◀ ▶ |
| 점프 | Space · ↑ · W | A | 점프 |
| 대시 (분석) | Shift · J | X | 대시 |
| 초안 발판 | ↓ + 점프 · K | B | 초안 |
| 답변 선택 | 1 · 2 · 3 · 4 | A · B · Y · X | 탭 |
| 일시정지 | ESC | Start | ⏸ |
| 음소거 | M | Back/Select | 소리 버튼 |

점프는 **누르고 있는 시간만큼 높이 뜁니다.** 짧게 톡 치면 낮게 뜁니다.

초안 발판은 공중에서 **최대 2번**까지 놓을 수 있고, 진짜 땅을 밟으면 다시 채워집니다.

## 규칙

- 시작 체력 5. 적과 부딪히거나 가시를 밟으면 1 감소
- 적은 **위에서 밟으면** 처치됩니다 (+20점). 대시로 들이받아도 됩니다 (+30점)
- 반복 작업(톱니바퀴)은 한 번 밟아서는 죽지 않습니다. 두 번 밟거나 대시로 부수세요
- 낭떠러지에 빠지면 체력 1을 잃고 직전 안전지대에서 다시 시작합니다
- 스테이지를 넘어가면 **체력이 가득 찹니다**. 부스에서 초반에 끝나지 않게 하기 위함입니다
- 크레딧(동전) +10점, 스테이지 클리어 +200점, 보스 격파 +500점
- 전 스테이지 클리어 시 남은 체력과 소요 시간으로 보너스가 붙습니다

리더보드는 브라우저의 localStorage에 저장됩니다. 부스 PC 한 대에서 하루치 기록을 모으는 용도입니다.

## 로컬에서 실행

**권장:** 폴더의 `서버로-열기.bat`을 더블클릭하세요. 로컬 서버가 뜨고 브라우저가 자동으로 열립니다.

```bash
cd cpw_k
python -m http.server 8849
# http://localhost:8849
```

> **`index.html`을 파일로 직접 열지 마세요(`file://`).**
> 브라우저 보안 정책 때문에 **게임패드가 인식되지 않습니다.**
> `file://`로 열면 타이틀 화면에 경고가 표시됩니다.

## 네트워크가 차단된 환경

폴더를 통째로 복사해 로컬 서버로 열면 그대로 동작합니다.
외부에서 받아오는 것은 **Google Fonts뿐**이며, 차단되어도 시스템 폰트(맑은 고딕 / monospace)로
대체되어 레이아웃이 깨지지 않습니다.

이미지·사운드·레벨 데이터는 **외부 파일이 하나도 없습니다.**
스프라이트는 코드로 그린 도트이고, 배경음과 효과음은 WebAudio로 합성합니다.
그래서 폴더 용량이 200KB 남짓입니다.

## 게임패드가 인식되지 않을 때

가장 흔한 원인은 두 가지입니다.

1. **패드 버튼을 아직 누르지 않음** — 브라우저는 지문 방지 정책상, 페이지에서 버튼이 한 번
   눌리기 전까지 패드를 노출하지 않습니다. 연결만 해서는 감지되지 않습니다.
2. **`file://`로 열었음** — 위 안내대로 로컬 서버로 여세요.

`Win+R` → `joy.cpl`로 OS 인식 여부를 먼저 확인하세요.

### 8BitDo Micro 사용법

본체 **하단 가장자리의 슬라이더(S / D / K)**로 모드를 바꿉니다. 버튼 조합이 아닙니다.
**D 모드**를 쓰세요. 모드를 바꾼 뒤에는 전원을 껐다 켜야 적용됩니다.

## 운영 팁 (부스)

- 1회 플레이는 **5~8분**입니다. 대기줄이 길면 1-3까지만 하고 넘겨도 메시지는 전달됩니다
- 화면 상단의 능력 칩은 **획득한 기능만 켜집니다.** 관람객에게 "지금 뭘 배웠는지" 보여주는 장치입니다
- 파워업 화면은 자동으로 넘어가지 않습니다. 이때 옆에서 실제 제품 화면을 함께 보여주면 전환이 자연스럽습니다
- 리더보드 초기화는 타이틀 화면의 `리더보드 > 기록 초기화`

## 파일 구조

```
cpw_k/
├─ index.html
├─ css/style.css
├─ js/
│  ├─ levels.js      스테이지 데이터 (배치 명령으로 생성)
│  ├─ sprites.js     코드로 그린 도트 스프라이트
│  ├─ game.js        물리 · 충돌 · 상태 관리
│  ├─ render.js      캔버스 렌더러
│  ├─ ui.js          오버레이 화면
│  ├─ quiz.js        스테이지 확인 문제
│  ├─ audio.js       WebAudio 8비트 사운드
│  ├─ gamepad.js     Gamepad API
│  ├─ leaderboard.js localStorage 기록
│  └─ main.js        진입점 · 입력 배선
└─ 서버로-열기.bat
```

### 스테이지를 고치려면

`js/levels.js`만 보면 됩니다. 좌표를 일일이 세지 않아도 되도록 배치 명령으로 씁니다.

```js
ground(0, 24)              // 0~24 칸에 지면
plat(12, 15, 11)           // 12~15 칸, 11행에 발판
coins(12, 15, 10)          // 그 위에 코인
foe(18, 14, 'mail')        // 메일 더미 적
put(66, 14, '?')           // 프롬프트 블록
col(72, 10, 14, '=')       // 세로 벽
```

고객사 맞춤이 필요하면 `quiz.js`의 문항과 `levels.js`의 스테이지 이름만 바꿔도 됩니다.
