# 코파일럿 아레나 (Copilot Arena)

밀려오는 잡무를 **맞는 도구**로 처리하는 부스용 웹게임.

빌드 도구 없이 순수 HTML/CSS/JS로 동작하는 정적 사이트입니다.

## 바로 해보기

**▶ https://microsoft.github.io/DungeonCopilot/cpa_k/**

## 왜 만들었나

기존 방식(스테이지를 다 지나면 퀴즈 팝업)은 **게임과 학습이 분리**돼 있었습니다.
5분 놀다가 문제 하나 푸는 구조라, Copilot은 껍데기고 실제로는 그냥 액션게임이었습니다.

이 게임은 다릅니다. **Copilot을 쓰는 행동이 곧 게임 조작입니다.**
초당 몇 번씩 누르는 버튼 4개가 그대로 Copilot 기능 4개이고,
"이 일에 뭘 쓸까"를 빠르게 고르는 것이 실력의 전부입니다.

## 규칙은 하나

**적의 테두리 색이 곧 필요한 도구입니다.**

| 몰려오는 잡무 | 통하는 도구 |
|---|---|
| 📧 밀린 메일 — 읽어야 할 게 200통 | 💬 **요약** `Copilot Chat` |
| 📊 쌓인 데이터 — 숫자만 잔뜩 | 📊 **분석** `Analyst` |
| 📄 백지 문서 — 첫 줄이 안 써짐 | 📄 **초안** `Copilot in Word` |
| ❓ 출처 불명 — 진짜인지 모를 정보 | 🔎 **근거** `Researcher` |

틀린 도구는 **죽이지 못하고**, 오히려 상대가 잠시 사나워집니다(빨라집니다).
설명을 읽는 대신 손해로 배웁니다.

조준은 자동입니다. 에임 실력이 아니라 **판단 속도**만 겨루게 하기 위함입니다.

## Work IQ — 맥락

화면 위쪽 게이지가 **Work IQ**입니다. 메일·회의·파일·채팅에서 모은 업무 맥락을 뜻합니다.

- 필드에 떨어지는 **맥락 조각**(✉️ 📅 📎 💬)을 몸으로 주우면 채워집니다
- **시간이 지나면 줄어듭니다.** 맥락은 신선해야 쓸모 있으니까요
- 맥락이 높을수록 한 발의 위력이 커집니다 (×1 → ×3)
- **맥락이 0이면 환각이 나옵니다.** 그럴듯하게 생긴 탄이 빗나가고 연속도 끊깁니다

> 맥락 없이 시키면 그럴듯한 헛소리가 나온다 — 이 게임에서 가장 전하고 싶은 한 줄입니다.

### 코워크

Work IQ를 100까지 채우면 **코워크**를 쓸 수 있습니다(Space).
9초 동안 에이전트 3기가 따라붙고, **도구 상관없이 모든 잡무가 처리됩니다.**
대신 맥락을 전부 쏟아붓기 때문에 게이지는 0이 됩니다.

## 프롬프트 상자 — 보너스일 뿐, 길을 막지 않습니다

가끔 노란 **?** 상자가 나타납니다. 밟으면 짧은 문제가 하나 뜹니다.

| | |
|---|---|
| 맞히면 | 점수 +300, **체력 +1**, 맥락 가득 |
| 틀리면 | **벌칙 없음.** 해설만 보고 넘어갑니다 |
| 무시하면 | 그냥 사라집니다 |

7초 제한이 있지만 넘겨도 아무 손해가 없습니다.
시험이 아니라 **아이템 뽑기**로 느껴지게 만든 장치입니다.

## 웨이브

10 웨이브입니다. 앞쪽은 한 종류만 나와 규칙을 안전하게 익히게 하고,
뒤로 갈수록 섞여서 판단 속도를 요구합니다.
마지막 10웨이브는 **분기 마감** — 네 종류가 한꺼번에 몰려옵니다.

체력 5. 적에게 부딪히면 1씩 줄고, 0이 되면 하루가 끝납니다.

## 조작

| 동작 | 키보드 | 마우스 | 게임패드 |
|---|---|---|---|
| 이동 | WASD · 방향키 | — | 왼쪽 스틱 · D-패드 |
| 발사 | Space(길게) | 클릭 유지 | RT · RB · 오른쪽 스틱 |
| 도구 1~4 | 1 2 3 4 | 도구 버튼 클릭 | A B X Y |
| 도구 앞뒤로 | Q · E | — | — |
| 코워크 | Space | 코워크 버튼 | LB |
| 답변 | 1 2 3 | 클릭 | A B X |
| 일시정지 | ESC | ⏸ | Start |
| 음소거 | M | 소리 버튼 | Back |

## 로컬에서 실행

**권장:** 폴더의 `서버로-열기.bat`을 더블클릭하세요.

```bash
cd cpa_k
python -m http.server 8861
# http://localhost:8861
```

> `index.html`을 `file://`로 직접 열면 **게임패드가 인식되지 않습니다.**

## 네트워크가 차단된 환경

폴더를 통째로 복사해 로컬 서버로 열면 그대로 동작합니다.
외부에서 받아오는 것은 **Google Fonts뿐**이며, 차단되어도 맑은 고딕으로 대체됩니다.

**외부 이미지·사운드 파일이 하나도 없습니다.** 스프라이트는 코드로 그린 도트,
소리는 WebAudio로 합성합니다.

## 운영 팁 (부스)

- 한 판은 **3~5분**입니다. 대기줄이 길면 5웨이브까지만 해도 메시지는 전달됩니다
- 타이틀 화면의 **상성표**를 먼저 보여주세요. 그것만 알면 바로 시작할 수 있습니다
- 관람객이 헤매면 "맥락 조각을 주우세요" 한마디면 충분합니다
- 일부러 맥락을 0으로 만들어 **환각**을 보여주는 시연이 반응이 좋습니다
- 리더보드 초기화는 타이틀의 `리더보드 > 기록 초기화`

## 파일 구조

```
cpa_k/
├─ index.html
├─ css/style.css
├─ js/
│  ├─ config.js      도구·적·웨이브 정의 (여기만 고쳐도 난이도 조절 가능)
│  ├─ sprites.js     코드로 그린 도트 스프라이트
│  ├─ game.js        전투·맥락·웨이브 로직
│  ├─ render.js      캔버스 렌더러
│  ├─ ui.js          오버레이 화면
│  ├─ quiz.js        프롬프트 상자 문제 10개
│  ├─ audio.js       WebAudio 8비트 사운드
│  ├─ gamepad.js     Gamepad API
│  ├─ leaderboard.js localStorage 기록
│  └─ main.js        진입점 · 입력 배선
└─ 서버로-열기.bat
```

고객사 맞춤이 필요하면 `quiz.js`의 문항과 `config.js`의 적 이름만 바꿔도 됩니다.
