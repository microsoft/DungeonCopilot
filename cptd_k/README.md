# 코파일럿 타워디펜스 (Copilot Tower Defense)

업무 요청이 길을 따라 밀려옵니다. **Copilot 에이전트를 배치해 막으세요.**

빌드 도구 없이 순수 HTML/CSS/JS로 동작하는 정적 사이트입니다.

## 바로 해보기

**▶ https://microsoft.github.io/DungeonCopilot/cptd_k/**

## 규칙은 하나

**에이전트는 자기 담당 업무만 처리합니다.** 잘못 배치하면 그 업무는 그냥 지나갑니다.

| 밀려오는 업무 | 처리할 수 있는 에이전트 |
|---|---|
| 📧 밀린 메일 | 💬 **요약** `Copilot Chat` |
| 📊 쌓인 데이터 | 📊 **분석** `Analyst` |
| 📄 백지 문서 | 📄 **초안** `Copilot in Word` |
| ❓ 출처 불명 | 🔎 **근거** `Researcher` |

담당이 아닌 업무가 지나가면 **무시됨** 표시가 뜹니다.
"어떤 일에 어떤 에이전트를 붙일까"를 배치 판단으로 익히게 하는 구조입니다.

받은편지함이 가득 차면(20건) 하루가 끝납니다.

## Work IQ — 맥락

화면 위 게이지가 **Work IQ**입니다. 메일·회의·파일·채팅에서 모은 업무 맥락입니다.

- 경로 주변에 떨어지는 **맥락 조각**을 클릭하거나 `X`로 회수하면 채워집니다
- **시간이 지나면 줄어듭니다.** 맥락은 신선해야 쓸모 있으니까요
- 맥락이 높을수록 모든 에이전트의 처리 속도가 빨라집니다
- **맥락이 낮으면 환각이 발생합니다.** 에이전트가 헛것을 처리하고 잠시 멈춥니다

> 실제 검증에서, 맥락 조각을 줍지 않으면 환각 18회에 처리 16건,
> 주우면 환각 0회에 처리 34건이었습니다. 맥락이 성과를 두 배로 만듭니다.

### 코워크

Work IQ를 100까지 채우면 **코워크**를 쓸 수 있습니다(`C`).
8초 동안 **모든 에이전트가 담당과 무관하게 모든 업무를 처리합니다.**

## 프롬프트 상자 — 보너스일 뿐입니다

가끔 나타나는 상자를 클릭하면 짧은 문제가 하나 나옵니다.

| | |
|---|---|
| 맞히면 | 크레딧·맥락 보상 |
| 틀리거나 무시하면 | **아무 벌칙 없음** |

길을 막지 않습니다. 전부 무시하고도 클리어할 수 있습니다.

## 웨이브

10 웨이브입니다. 앞쪽은 한 종류만 나와 상성을 안전하게 익히게 하고,
뒤로 갈수록 섞여서 배치 재구성을 요구합니다.

마지막 10웨이브는 **분기 마감** — 네 종류가 한 덩어리로 뭉친 보스입니다.
한 종류 에이전트만으로는 절대 못 잡고, 네 종류를 모두 갖춰야 뚫립니다.
복잡한 일에는 여러 Copilot 기능이 함께 필요하다는 뜻입니다.

## 조작

| 동작 | 키보드 | 마우스 | 게임패드 |
|---|---|---|---|
| 에이전트 선택 | 1 2 3 4 | 하단 버튼 | — |
| 배치 | — | 빈 자리 클릭 | 커서 이동 + A |
| 업그레이드·판매 | — | 배치된 타워 클릭 | A |

| 다음 웨이브 | Space | 버튼 | — |
| 일시정지 | ESC | ⏸ | Start |
| 음소거 | M | 소리 버튼 | Back |

## 로컬에서 실행

**권장:** 폴더의 `서버로-열기.bat`을 더블클릭하세요.

```bash
cd cptd_k
python -m http.server 8871
```

> `file://`로 직접 열면 게임패드가 인식되지 않습니다.

## 네트워크가 차단된 환경

폴더를 통째로 복사해 로컬 서버로 열면 그대로 동작합니다.
외부 의존은 **Google Fonts뿐**이고, 차단되어도 맑은 고딕으로 대체됩니다.
이미지·사운드 파일이 하나도 없습니다(도트는 코드로, 소리는 WebAudio 합성).

